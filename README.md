# AUC Formula E planning website

Static planning website for AUC Formula E, FSUK Concept Class 2027.

Open index.html or publish this folder using GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).

No build or paid services are needed. Visitors can open the public website without a ChatGPT account.

Plans are saved in each browser separately. Use JSON backup and Import to transfer a plan. Moving between hosting addresses does not transfer browser storage automatically.

Team captains: Haneen Kotb and Omar Badawy. Task owners are chosen by the user.

Official competition deadlines remain unconfirmed; example internal dates are editable.
